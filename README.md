# ZUNO 🎧

A modern Android music player with API-based song discovery and background audio playback.

## Features

- 🎵 API-based song discovery
- 🎤 Song title and artist information
- 🖼️ Album artwork
- ▶️ Play / Pause
- 🎧 Background audio playback
- 🔒 Playback continues when the phone is locked
- 📱 Simple and clean Android UI

## Technology

- Kotlin
- XML
- RecyclerView
- Retrofit
- Gson
- Coil
- AndroidX Media3
- ExoPlayer
- MediaSession

## App Flow

Home → Select Song → Now Playing → Play/Pause → Background Playback

## Note

The app uses bundled original demo audio files for playback while song metadata and artwork are obtained through a public music API.
