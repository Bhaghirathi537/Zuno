# PulsePlay Submission Checklist

## Before submission

- [ ] Open the project in Android Studio.
- [ ] Sync Gradle successfully.
- [ ] Run on a physical Android phone.
- [ ] Confirm at least 5 API songs appear.
- [ ] Confirm artwork appears.
- [ ] Confirm a song opens Now Playing.
- [ ] Confirm Play works.
- [ ] Confirm Pause works.
- [ ] Minimize the app while playing.
- [ ] Confirm audio continues.
- [ ] Lock the phone while playing.
- [ ] Confirm audio continues.
- [ ] Confirm Android media controls appear.
- [ ] Test Retry after temporarily disabling internet.
- [ ] Generate a release APK.
- [ ] Install the release APK on a phone.
- [ ] Create a public GitHub repository.
- [ ] Push the complete project.
- [ ] Check that no passwords/API secrets are committed.
- [ ] Submit the GitHub URL and APK in the recruitment form.
